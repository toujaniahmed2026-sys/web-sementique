3. TESTS DANS LA CONSOLE PYTHON
---------------------------------------------------------------------
python

>>> from graph import G_BRUT, G_INFERE
>>> print(len(G_BRUT), len(G_INFERE))
>>> import queries as q
>>> for r in q.films(G_BRUT): print(r)
>>> for r in q.realisateurs(G_BRUT): print(r)
>>> print(len(q.personnes(G_BRUT)), len(q.personnes(G_INFERE)))
>>> print(len(q.participations(G_BRUT)), len(q.participations(G_INFERE)))

Exemple Hend Sabri (ce que chaque graphe sait sur elle) :
>>> from rdflib import URIRef
>>> hend = URIRef("http://example.org/cinema#HendSabri")

>>> for p, o in G_INFERE.predicate_objects(hend): print(p, o)

Quitter la console :

Si des lignes "..." apparaissent : Ctrl + C, puis retaper la ligne

---------------------------------------------------------------------
4. LANCER LE WEB SERVICE (terminal)
---------------------------------------------------------------------
python app.py

Le service tourne sur http://127.0.0.1:5000
Laisser ce terminal ouvert. Pour arreter : Ctrl + C.
Ouvrir les URL ci-dessous dans le navigateur, ou dans un
DEUXIEME terminal avec curl.exe.

---------------------------------------------------------------------

---------------------------------------------------------------------
http://127.0.0.1:5000/api/films
http://127.0.0.1:5000/api/films?annee_min=2017
http://127.0.0.1:5000/api/films?duree_min=100
http://127.0.0.1:5000/api/films/UnFils
http://127.0.0.1:5000/api/genres/Drame/films
http://127.0.0.1:5000/api/realisateurs
http://127.0.0.1:5000/api/realisateurs?inference=true
http://127.0.0.1:5000/api/acteurs/Sami/films
http://127.0.0.1:5000/api/salles
http://127.0.0.1:5000/api/personnes?inference=false
http://127.0.0.1:5000/api/personnes?inference=true
http://127.0.0.1:5000/api/inference/comparaison

Exemples avec curl (deuxieme terminal) :
curl.exe http://127.0.0.1:5000/api/films/UnFils
curl.exe "http://127.0.0.1:5000/api/films?annee_min=2017"

---------------------------------------------------------------------
6. TESTER LES ERREURS
---------------------------------------------------------------------
Erreur 400 (parametre invalide) :
http://127.0.0.1:5000/api/films?annee_min=abc

Erreur 404 (ressource inconnue) :
http://127.0.0.1:5000/api/films/Inconnu

Avec curl, afficher aussi le code HTTP :
curl.exe -i "http://127.0.0.1:5000/api/films?annee_min=abc"
curl.exe -i http://127.0.0.1:5000/api/films/Inconnu

7. AVANT LA DEMO : RETIRER "MON FILM"

  -> ce n'est pas une panne : erreur 400 volontaire, utiliser un nombre.

python app.py impossible : port 5000 deja utilise
  -> fermer l'autre terminal qui fait tourner app.py (Ctrl + C).
